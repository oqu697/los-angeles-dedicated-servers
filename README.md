## 常见问题

**30M 精品 CN2 够不够用？**

看单用户的并发需求。30M 独享跑一个日 IP 几千的外贸站绰绰有余，跑视频就废了。Hostease 把 30M 精品 CN2 定位在“面向中国大陆访问优化”，100M/1Gbps 国际带宽定位在“全球业务部署”，两档不是升级关系，是用途不同。你的用户主要在中国大陆，30M 精品 CN2 比 100M 国际线路的实际体验好；用户在全球，选国际带宽。

**10Gbps 什么业务才需要？**

大文件下载、视频分发、直播推流、软件更新源、高并发静态资源。普通企业站和中小电商从 1Gbps 起步就够，10Gbps 的门槛价在 $300 以上，不是必须花的钱。

**独立服务器和 VPS 差在哪？**

独享物理硬件和资源隔离。洛杉矶 VPS 的促销价能低到 $5.99/月甚至年付几美元，和独服的 $40 起不是一个品类，别拿 VPS 的价格来锚定独服预算。反过来，独服能给你的东西 VPS 给不了：完整系统权限、独享 CPU 和内存、可指定的 IP 段、可定制的硬件。

**月付还是年付？**

Lightlayer 这次活动的规则是季付、半年付、年付可以在活动价基础上叠加额外折扣，每款产品每位客户限购 2 台。先月付跑一个月，确认线路在你目标时段的实际表现，再转长周期，比一上来签年付稳。
